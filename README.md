## 1) Архитектура проекта

Три программы, которые не знают друг о друге и общаются через посредника:

- **popup.ts** (окно расширения) — сохраняет данные группировки каналов со страницы расширения в Local Storage (Chrome);
- **chrome.storage** — посредник, общее хранилище данных;
- **content.ts** (работает на YouTube) — считывает данные из хранилища и отображает результаты группировки на странице YouTube (либо в отдельном разделе, либо во вкладке с подписками слева).

```text
┌─────────────────────┐
│ popup.ts            │
│ окно расширения     │
└──────────┬──────────┘
           │
           │ сохраняет
           ▼
┌─────────────────────┐
│ chrome.storage      │
└────────────────────┘
           │
           │ читает
           ▼
┌─────────────────────┐
│ content.ts          │
│ работает на YouTube │
└──────────┬──────────┘
           │
           ▼
  изменяет DOM YouTube
```

## 3) Команды для сборки и прочего

### a. tsc (TypeScript Compiler)

Главный инструмент для работы с языком TypeScript.

Что делает:
- переводит (транслирует) код из TypeScript в обычный JavaScript;
- находит ошибки в коде.

### b. npm (Node Package Manager)

Огромный каталог готовых программ и библиотек для разработки + программа для управления ими.

Что делает:
- скачивает сторонний код для проекта, обновляет его и запускает вспомогательные действия;
- `npm run <имя_команды>` — запускает скрипт, прописанный в `package.json` (например, команду `tsc` можно скрыть за `npm run build`).

### Основные команды

- `tsc --version` — проверить версию компилятора;
- `tsc ИмяФайла.ts` — скомпилировать конкретный файл;
- `node -v` / `npm -v` — проверить версии Node.js и npm;
- `npm run dev` — запустить скрипт разработки.

> **Важно (Windows):** система без прав запуска скриптов (права не выданы), поэтому все команды запускаются с суффиксом `.cmd`:
>
> ```bash
> npm.cmd run dev
> ```
