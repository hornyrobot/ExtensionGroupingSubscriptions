1) Архитектура проекта:

Три программы, которые не знают друг о друге и общаясь через посредника - сохраняют данные группировки каналов со страницы расширения В Local Storage (Chrome). Оттуда данные другой программой будут считываться И отображать результаты группировки на странице YouTube (ЛИБО в отдельном разделе, ЛИБО во вкладке с подписками, которая слева в окне браузера)

┌──────────────┐
│ popup.ts     │
│ окно расширения
└──────┬───────┘
       │
       │ сохраняет
       ▼
┌──────────────┐
│ chrome.storage │
└──────┬────────┘
       │
       │ читает
       ▼
┌──────────────┐
│ content.ts   │
│ работает на YouTube
└──────┬───────┘
       │
       ▼
    изменяет DOM YouTube

3) Комманды для билдинга и почего:

a. tsc (TypeScript Compiler) Это главный инструмент для работы с языком TypeScript.Что делает: Переводит (транслирует) ваш код из специального языка TypeScript в обычный JavaScript. Также находит ошибки в коде.

b. npm (Node Package Manager) Это огромный магазин (каталог) готовых программ и библиотек для разработки, а также программа для управления ими.Что делает: Скачивает сторонний код для вашего проекта, обновляет его и запускает вспомогательные действия.
(npm run <имя_команды> — запускает скрипт, который прописан в вашем файле проекта (например, команду tsc можно скрыть за словом npm run build).)

Основные для билднига это "tsc --version" и "tsc НазваниеФайлаСкрипта.ts" + "node -v" или "npm -v" и  "npm run dev"
т.к у меня винда без прав запуска скриптов (не стал давать), то все эти манды делаем с + ".cmd" например: npm.cmd run dev
